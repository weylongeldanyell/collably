# Collably prototype

A responsive web + PWA-style front-end prototype for a marketplace that helps buyers hire online teams such as video editors, clippers, designers, social media workers and developers.

## Run it
Open `index.html` in a browser. For full PWA/service-worker support, serve the folder from a local web server.

## Included
- Instagram-inspired dark feed
- Search bar
- Talent discovery and role filters
- Buyer/worker signup choice
- Worker profile cards
- Start-project/message flow
- Responsive mobile layout
- PWA manifest + service worker starter

## Next build stage
For a real production app, add a backend for accounts, profiles, portfolios, chat, payments, reviews, job posts, search, moderation and notifications. A React/Next.js front end with a database such as PostgreSQL would be a strong path.
