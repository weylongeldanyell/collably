# Collably v0.2

Responsive front-end prototype for the creator/team marketplace.

New in v0.2:
- Buyer and worker signup flow
- Worker profiles with bios, skills, rates and ratings
- Search across workers and skills
- Discover filters
- Portfolio/profile page
- Job board with post-a-job flow
- Worker-to-buyer message flow
- Application flow
- Responsive mobile navigation

This is still a front-end prototype. Data is stored only in browser memory and resets on refresh. A production version needs authentication, database, storage, payments, moderation and a backend.
